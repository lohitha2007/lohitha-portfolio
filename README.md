# Galeti Lohitha — Personal Portfolio Website

A responsive personal portfolio website created with **HTML5 and CSS3** to introduce me, present my technical skills and projects, summarize my education and internship experience, and provide professional contact links.

## About the Project

This project was developed as an introductory front-end web development project. The page uses semantic HTML for its structure and a separate CSS stylesheet for visual design and responsive layouts. It is designed to be simple to navigate on desktop and mobile screens.

## Website Sections

- **Home:** Introduction, current role, areas of interest, and navigation buttons.
- **About Me:** Short biography and education details.
- **Technical Skills:** Programming languages, web technologies, tools, and core concepts.
- **Featured Projects:** Rainfall Prediction System and Personal Portfolio Website.
- **Internship & Certifications:** Network engineering internship experience and selected learning credentials.
- **Contact:** Email, GitHub, and LinkedIn links.

## Technologies Used

- **HTML5** — semantic page structure and content.
- **CSS3** — colors, typography, spacing, cards, hover/focus styling, and page layout.
- **CSS Grid and Flexbox** — arranging page content and cards.
- **CSS media queries** — adapting the layout for smaller screens.

> This project uses HTML and CSS only. It does not require JavaScript, a backend, a database, or a package installation.

## Run the Website Locally

1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code **Live Server** extension if it is installed.
5. Test the navigation links and contact links, and resize the browser to check the responsive layout.

No build command or dependency installation is required.

## Publish with GitHub Pages

1. Push `index.html`, `style.css`, and `README.md` to the root of a public GitHub repository.
2. Open the repository's **Settings** page and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then click **Save**.
5. Wait for the deployment to finish. GitHub Pages will display the published site URL in the Pages settings.
6. Open that URL and check that the page and stylesheet load correctly.

The live URL is not listed here because it depends on the final GitHub repository name and successful deployment.

## Customization

- Update the content in `index.html`.
- Change colors, typography, spacing, and layouts in `style.css`.
- Keep `index.html` and `style.css` in the same directory so the stylesheet link continues to work.
- Add project repository links or screenshots only after confirming that they exist and are ready to share.

## Notes

- The contact section provides links; it is not a backend-powered contact form.
- Review personal details, project descriptions, and external profile links before submitting or publishing the site.
- If screenshots are required for an internship submission, capture the finished site in both desktop and mobile layouts and include them separately as requested by the organizer.
